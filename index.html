كل التشفيرات

🔤 Caesar / ROT13

ROT13 (إزاحة 13) نفسه للتشفير والفك.

🧮 XOR

لو الإدخال hex صالح بيتعامل معه كبايتات، غير كذا يأخذه كحروف ASCII عادية.

🚂 Rail Fence

لو تعرف عدد الصفوف بالضبط حطه، غير كذا بيطلع كل الاحتمالات من 2 إلى 6.

الصق الـ Hash

التحديد يعتمد على طول الـ hash وصيغته. لفكّه جرب: CrackStation أو hashes.com أونلاين، أو hashcat/john محليًا مع wordlist متل rockyou.txt.

ارفع الصورة

🔎 بحث عكسي يدوي بنفس الصورة

المتصفح لأسباب أمنية ما يقدر يرفع صورتك تلقائيًا لمواقع خارجية من صفحة زي هذي (قيود CSP) — ولا توجد أداة ويب تقدر فعليًا تتجاوز هذا القيد. الحل: اضغط زر النسخ، وبعدين روح لأي موقع من الأزرار وافتح صندوق البحث واضغط Ctrl+V (أو Cmd+V على Mac) ليلصق الصورة مباشرة.

منهجية التفكير حسب الفئة

🎯 الخطوات العامة اللي تسويها بأي تحدي (بالترتيب)
  1. اقرأ اسم ووصف التحدي عدل — فيه تلميح دايمًا، غالبًا الاسم نفسه يدلك على الفئة أو الأسلوب
  2. حمّل الملف/افتح الرابط المرفق، وحدد نوعه (نص، صورة، ملف تنفيذي، pcap، موقع...)
  3. طبّق الفحص الأولي حسب النوع (تبويب الفئة تحت أو تبويب "تحليل صورة")
  4. لو طلعت لك بيانات غريبة (نص عشوائي/أرقام)، رجّعها لتبويب "فكّاك التشفير"
  5. دوّر دايمًا على نمط flag{...} أو CTF{...} بأي مخرجات تحصلها — هذا شكل الفلاق بأغلب منصات CyberTalents، ولما تشوفه يكون هذا جوابك النهائي اللي تسلمه بالموقع
  6. لو انحشرت، بدّل زاوية التفكير (فئة ثانية) أو دور على Writeups لتحديات مشابهة بالاسم نفسه لتتعلم الأسلوب
🔑 Cryptography
  • اسأل نفسك: النص base64؟ (غالبًا ينتهي بـ = ويحتوي أحرف وأرقام فقط)
  • شكل hex؟ (أرقام 0-9 وحروف a-f فقط، طوله زوجي)
  • فيه نقط وشرطات متباعدة؟ جرب Morse. أرقام بس 0 و1؟ جرب Binary
  • نص عادي لكن غريب؟ جرب Caesar/ROT13 (كل الإزاحات)
  • أرقام كبيرة + كلمة RSA/p,q,n,e؟ استخدم RsaCtfTool أو factordb.com لتفكيك n
  • XOR؟ لو عندك المفتاح جرب كل بايت، أو known-plaintext إذا تعرف جزء من الفلاق (مثلاً flag{)
  • Vigenère أو تشفير غير مذكور هنا؟ استخدم CyberChef (أقوى أداة أونلاين لأي تشفير تقريبًا)
🌐 Web Security
  • افحص مصدر الصفحة (Ctrl+U) والـ Comments المخفية وملفات JS
  • جرب /robots.txt, /.git/, /admin, /backup
  • SQL Injection: جرب ' OR 1=1-- بالفورمز، أو استخدم sqlmap
  • افحص الكوكيز — هل فيها قيمة base64 أو JWT تقدر تعدلها؟
  • IDOR: غيّر الـ ID بالرابط (user_id=1 → 2) وشوف وش يصير
  • LFI: جرب ?page=../../../../etc/passwd
  • افحص الـ Headers بالـ Network tab (F12) — أحيانًا الفلاق بالـ Response Headers
🔍 Digital Forensics
  • أول خطوة دايمًا: file filename ثم strings filename | grep -i flag
  • صور: افحص الميتاداتا بـ exiftool (أو تبويب "تحليل صورة" بهذي الأداة)، وجرب steganography بـ steghide أو zsteg
  • ملف يبين تالف؟ افحص الـ magic bytes بـ Hex Editor وقارنها بالصيغة الصحيحة (PNG يبدأ بـ 89 50 4E 47)
  • ملفات مخفية جوا ملف ثاني؟ جرب binwalk -e filename
  • PCAP؟ افتحه بـ Wireshark وتابع TCP Stream، دور على HTTP/FTP credentials
  • Memory dump؟ استخدم Volatility
  • ملف مضغوط بباسورد؟ جرب fcrackzip أو John the Ripper مع rockyou.txt
⚙️ Malware / Reverse Engineering
  • ابدأ بـ strings binary | grep -i flag — أحيانًا الفلاق موجود مباشرة!
  • حدد نوع الملف بـ file ثم افتحه بـ Ghidra أو IDA Free
  • دور على دوال باسم مريب متل check_flag, validate, strcmp
  • فيه تشفير جوا الكود؟ تتبعه يدويًا أو اكتب سكريبت Python يحاكي نفس العملية بالعكس
  • استخدم x32dbg/x64dbg أو gdb للتتبع الديناميكي (breakpoints عند المقارنات)
🛰️ Network Security
  • Wireshark: فلتر بـ http أو ftp أو dns حسب نوع الترافيك
  • Follow TCP/HTTP Stream يطلع المحادثة كاملة نصيًا
  • دور على بيانات دخول متبادلة بنص واضح
  • بروتوكول غريب؟ ابحث باسمه + "wireshark dissector"
🕵️ OSINT
  • صورة؟ افحص EXIF لموقع GPS (تبويب "تحليل صورة")، أو استخدم بحث عكسي
  • اسم مستخدم؟ جرب نفس الاسم بمواقع تانية (Twitter, GitHub, LinkedIn)
  • دومين/إيميل؟ جرب whois, Shodan، أو قواعد بيانات التسريبات العامة
  • استخدم theHarvester لجمع المعلومات تلقائيًا
📱 Mobile Security
  • APK: فك الضغط بـ apktool d app.apk وافحص AndroidManifest.xml والكود بـ jadx-gui
  • دور على Hardcoded secrets/keys جوا كود Java/Kotlin المفكوك
  • افحص strings.xml وملفات assets داخل الـ APK

✅ عادات عامة تفيدك بأي تحدي

  • لما تستلم ملف: file ثم strings ثم exiftool — بالترتيب، دايمًا
  • الفلاق غالبًا بصيغة flag{...} أو CTF{...} — دور عليها بالـ grep مباشرة
  • تعبت بطريقة وحدة؟ بدّل الزاوية (Forensics بدل Crypto مثلاً)
  • اقرأ اسم التحدي ووصفه كويس — غالبًا فيه تلميح مباشر بالاسم نفسه
